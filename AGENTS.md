# Quick Launcher Agent Conventions

## Directory Layout

- `src/`: React and TypeScript frontend modules.
- `src-tauri/src/`: Rust native modules and Tauri commands.
- `docs/`: README screenshots and documentation assets.
- `public/`: Static frontend assets.
- `dist/`: Vite frontend build output; generated, do not edit manually.
- `src-tauri/target/`: Standard Rust/Tauri build directory; generated.
- `src-tauri/target/release/bundle/`: Release installers generated by Tauri.

## Build and Packaging

- Use `npm.cmd run build` for frontend-only builds.
- Use `npm.cmd run tauri:build` for Windows packaging.
- Do not create alternate packaging directories such as `target-package/`.
- Do not commit generated build directories or runtime data.
- Publish release artifacts from `src-tauri/target/release/`.

## Documentation

- Keep README focused on product features, usage, and development instructions.
- Put version-specific change notes in GitHub/Gitee Releases, not in README.
